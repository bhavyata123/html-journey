# 📚 Day 01 — Foundations

## 🧩 What is HTML?
HTML is a markup language used to structure web content using tags.

## 💻 Frontend Development
Frontend includes:
- HTML (structure)
- CSS (design)
- JavaScript (behavior)

## 🌍 How the Web Works
User types domain → DNS → Server → Browser displays webpage.

## 📡 DNS
DNS converts domain names into IP addresses.

## ☁️ Hosting
Hosting stores website files on internet servers.
